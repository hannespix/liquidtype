04 / Inspiration

Liquid Type ist nach Inspiration von Matthias Sütterlin entstanden und basiert teilweise auf seinen Ideen, etwa dem flüssigen Mauszeiger, der mit der Schrift verschmilzt.

Matthias Sütterlin auf GitHub: github.com/matthiassuetterlin

05 / Über Liquid Type

Liquid Type ist ein interaktives Schriftexperiment: Text wird zu einer zweidimensionalen Flüssigkeit, die sich ziehen, schütteln und platzen lässt. Die Seite läuft vollständig im Browser und bindet keine externen Dienste ein.
